Flat static site composed of three sibling HTML pages (`index.html`, `about.html`, `projects.html`) sharing one stylesheet (`style.css`) and one script (`script.js`), plus an external Typed.js bundle under `vendor/typed.umd.js`. Each page embeds a single inline `<svg class="svg-sprite">` containing reusable icon `<symbol>` definitions (LinkedIn, GitHub, Facebook, arrows, camera, code, etc.) referenced via `<use href="#i-..."/>`, so icons are duplicated per page rather than centralized. The root CSS defines a design-system token layer in `:root` (`--bg`, `--teal`, `--grad`, `--font-body`, `--font-display`, `--radius`, `--header-h`, `--container`) that all components consume; there is no build step or framework — assets are served directly from GitHub Pages. `script.js` is wrapped in an IIFE with `"use strict"` and wires up scroll progress, mobile nav toggle, IntersectionObserver-based reveal animations, pointer spotlight effects, the Typed.js hero roles, lazy-loaded Google Drive video iframes, and an accessible gallery lightbox with keyboard/touch navigation. External resources (Google Fonts, Typed.js) are loaded via `preconnect` and `defer`; the site ships its own SVG sprite instead of relying on an icon library.
